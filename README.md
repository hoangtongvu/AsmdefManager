# Asmdef Manager

## Introduction

**Asmdef Manager** is a `.asmdef` references manager.

## Installation

To install, paste the following URL into Unity's **Package Manager**:

1. Open **Package Manager**.
2. Click the **+** button.
3. Select **"Add package from git URL..."**.
4. Enter the following URL:
```bash
https://github.com/hoangtongvu/AsmdefManager.git#0.1.0
```

## Getting Started

Open the tool from: `Tools/Asmdef Manager`
