# Asmdef Manager

## Introduction

**Asmdef Manager** is a tool that helps managing `.asmdef` references in a single window.

## Features

- List all user-defined assemblies and their assembly references in a single window
- Add/Remove assembly references to/from the selected assembly
- Sort and auto-sort assembly references based on categories

## Installation

To install, paste the following URL into Unity's **Package Manager**:

1. Open **Package Manager**.
2. Click the **+** button.
3. Select **"Add package from git URL..."**.
4. Enter the following URL:
```bash
https://github.com/hoangtongvu/AsmdefManager.git#0.2.0
```

## Getting Started

Open the tool from: `Tools/Asmdef Manager`
